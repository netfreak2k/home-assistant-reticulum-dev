# N2K RNS Gateway — Public Beta

N2K RNS Gateway brings Reticulum and LXMF messaging into Home Assistant.

The current beta includes persistent Reticulum identity, LXMF messaging,
contacts, delivery tracking, retry handling, network path information,
RNode support, TCP/AutoInterface support and an integrated diagnostic
system.

The current software stack has passed remote acceptance testing including
restart persistence, messaging, delivery tracking and integrated self-tests.

One validation item remains open: physical RNode USB disconnect/reconnect
behaviour has not yet been tested on site.

This beta is intended for technically experienced users who are comfortable
testing development software and providing useful bug reports.
