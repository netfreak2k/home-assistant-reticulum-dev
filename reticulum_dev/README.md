# N2K RNS Gateway DEV

Home Assistant add-on for connecting Home Assistant to the Reticulum
Network Stack and LXMF messaging.

## Features

- Persistent Reticulum identity
- LXMF messaging
- Contact management
- Delivery status
- Reticulum path / hop information
- TCP interfaces
- AutoInterface
- RNode / serial support
- Home Assistant Ingress
- Local-first operation
