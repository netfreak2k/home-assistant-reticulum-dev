# N2K RNS Gateway DEV 1.30.58-beta1

## N2K Mesh Plaza

Demo Mode has been transformed into a continuous animated stream loop.

### New visual layer

The Demo now contains a shared animated Reticulum environment with:

- flowing Reticulum routes
- moving signal packets
- pulsing mesh nodes
- floating RNS / LXMF / Home Assistant broadcast panels
- continuous N2K Mesh Plaza ticker

### Scene-specific motion

All 17 scenes now influence the background differently.

Examples:

- Local First gathers and connects nodes
- Reticulum Path scenes increase route flow
- Transport separates route accents
- LXMF emphasizes moving message packets
- Living Mesh uses the strongest cinematic motion
- RNode increases radio-style pulsing
- Store & Forward pauses and resumes packet behaviour
- Monitoring increases broadcast-wall activity
- Home Assistant emphasizes automation/event flow
- Secure LXMF -> HA emphasizes the trusted event side
- Development uses cyclic stepped motion
- Finale activates the complete digital Mesh meeting place

### Stream goal

The result is designed for long Twitch / YouTube / social demo loops so the background remains active even when a scene is being narrated.

### Concept

N2K Mesh Plaza is an original tribute to the idea of a shared participatory digital meeting place and network television, expressed entirely in the project's own N2K visual language.

### Preserved behaviour

Unchanged:

- 17 scenes
- nominal minimum runtime: 227 seconds / 03:47
- narration synchronization
- speaker enabled by default
- subtitles disabled by default
- privacy-safe synthetic data
- capture formats
- bright stream look

### Accessibility

The new background animation respects `prefers-reduced-motion`.
