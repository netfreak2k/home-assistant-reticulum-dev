# N2K RNS Gateway 1.14.0-dev

## Beta Candidate

This build marks the first feature-frozen beta candidate of the
N2K RNS Gateway Home Assistant add-on.

The current build provides a locally hosted Reticulum and LXMF gateway
with an integrated Home Assistant Ingress interface.

### Highlights

- Persistent Reticulum identity
- LXMF messaging
- Contacts and local aliases
- Delivery and retry status
- Reticulum path and hop visibility
- Queue awareness
- Contact QR codes
- RNode support
- TCP and AutoInterface support
- Integrated diagnostic self-test
- N2K RNS Gateway interface and branding

### Test status

The complete remote beta acceptance test passed.

The only outstanding acceptance item is the physical RNode USB
disconnect/reconnect test, which must be performed on site.

### Development state

Feature freeze is active.

The next changes should focus on defects, stability and final hardware
validation.
